Каждый код — как отдельная дорожка к пляжу: нельзя, чтобы одна дорожка была началом другой.

Слайд 2 · теория

Что говорит условие Фано

Никакое кодовое слово не должно быть началом другого кодового слова.

02
✅

Можно

0, 10, 110, 111

Ни один код не является началом другого.

⛔

Нельзя

0, 01, 10

Код 0 является началом кода 01.

🧠

Зачем это нужно

Чтобы сообщение можно было расшифровать однозначно, без выбора между несколькими вариантами.

Главная проверка

  1. Новый код не должен начинаться с уже известного кода.
  2. Уже известный код не должен начинаться с нового кода.
  3. Коды не должны совпадать.

Ловушка задания

Слова «с наименьшим числовым значением» и «с наибольшим числовым значением» проверяются только среди кодов минимальной длины.

Слайд 3 · алгоритм

Рабочий алгоритм

Подходит для задач на поиск одного кода и для задач на минимальную длину слова.

03
1

Выпиши известные коды

Отдельно отметь короткие коды: именно они чаще всего запрещают целые ветки.

2

Иди по длинам

Проверяй сначала коды длины 1, потом 2, потом 3 и так далее.

3

Вычёркивай запрещённые ветки

Если есть код 0, то все коды, начинающиеся на 0, уже запрещены.

4

Учитывай условие выбора

Если несколько вариантов одной длины — выбирай наименьший или наибольший по условию задачи.

Слайд 6 · практика 3 · средняя

Кратчайший код для буквы Г

id 11706. Для букв А, Б, В известны коды: А – 1010, Б – 1100, В – 0.

06
🍋
Летняя предыстория

В летнем кафе добавляют новую метку для напитка «Гранитный лимонад». Нужно выбрать код для буквы Г так, чтобы кассовая система не путала его с уже существующими кодами.

Условие

Укажите кратчайшее кодовое слово для буквы Г, при котором код будет допускать однозначное декодирование. Если таких кодов несколько, укажите код с наибольшим числовым значением.

Подсказка

Код 0 запрещает все варианты, которые начинаются с нуля. Код 1 нельзя взять, потому что он будет началом кодов 1010 и 1100.

Проверка ответа

Введите ответ и нажмите «Проверить».

Показать решение
Длина 1 и 2 не подходит. На длине 3 подходят 100 и 111. Нужно взять наибольшее числовое значение, значит ответ: 111.

Команда придумывает код для названия лодки «КАЗАЧКА». Чем короче коды для часто встречающихся букв, тем быстрее передать слово по рации.

Условие

Сообщения содержат буквы А, З, К, Н, Ч. Коды для А, К и Ч неизвестны. Сколько двоичных знаков потребуется для кодирования слова КАЗАЧКА, если оно закодировано минимально?

# История развития информатики

Премиальная интерактивная HTML-страница в музейной тёмной стилистике.

## Запуск

Откройте `index.html` в браузере (двойной клик) или через локальный сервер:

```bash
cd history-map
python3 -m http.server 8765
```

Все данные и карта подключены локальными скриптами — сетевые запросы к API не нужны.  
Шрифты Google подключаются опционально; при офлайне сработают системные запасные.

## Структура

```
history-map/
├── index.html
├── styles.css
├── script.js
├── data/stages.js          ← замените тексты, даты, координаты, картинки здесь
├── assets/
│   ├── map/world-geo.js    ← SVG-карта мира (GeoJSON)
│   ├── placeholders/       ← SVG-заглушки
│   └── portraits/          ← сюда позже положите реальные портреты
└── vendor/d3.min.js
```

## Замена данных

Редактируйте массив `window.historyStages` в `data/stages.js`.  
Интерфейс менять не нужно. Координаты: `[longitude, latitude]`.

| Поле | Где видно |
|---|---|
| `description`, `fact`, `image` | левая панель |
| `modal.text`, `modal.image` | модальное окно по клику на точку |
| `modal.title`, `modal.fact` | опционально в модалке |

Текст слева и текст в модалке **разные** — правьте независимо.
